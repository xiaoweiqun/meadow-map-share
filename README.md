# Meadow Map Share

一个用于分享和管理 Meadow 自定义地图的 Rain Meadow 模组。

A Rain Meadow mod for sharing and managing custom Meadow maps.

## 功能 Features

- 分享和管理自定义地图
- 支持多语言文本
- 与 Rain Meadow 配合使用

- Share and manage custom maps
- Multi-language text support
- Designed to work with Rain Meadow

## 安装 Installation

将 `rainmeadow_arena_map_share` 文件夹复制到：

Copy the `rainmeadow_arena_map_share` folder to:

```text
Rain World/StreamingAssets/mods/
```

然后启动游戏并启用模组。

Then launch the game and enable the mod.

## 依赖 Requirements

- Rain World
- Rain Meadow
